# Community expectations

Be respectful, specific, and constructive. Critique code and ideas, not people.
Welcome questions from contributors with different backgrounds and experience.

Harassment, threats, discriminatory language, targeted personal attacks, and
sharing someone else's private information are not acceptable.

Maintainers may edit or remove content, close discussions, or restrict participation
when these expectations are violated. Decisions should be proportionate and include
an explanation where practical. Do not repost removed private information.

For abuse involving public GitHub content, use GitHub's **Report content** action.
For project security vulnerabilities, follow [SECURITY.md](SECURITY.md).
