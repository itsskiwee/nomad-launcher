Save folders

Sync

The newer copy of each save wins. Nothing is deleted, and a save replaced by a newer one from another device is kept in Nomad Saves/…/.previous. Close the emulator before syncing.

Now playing

Music access

Whatever is playing on the phone shows on Home with play, pause and skip.

Time played

Tracks games launched through Nomad after usage access is enabled. Updates when you return. Emulator menus count as playtime; switching games inside an emulator stays attributed to the game launched here.

RetroAchievements

Username
Web API keyretroachievements.org › Settings › Keys

Progress shows in each game’s ⋯ menu. Games are matched by file hash, like RetroArch does, for cartridge systems, arcade and PSP ISOs. Your username, key and the matched game ids go to retroachievements.org; game files never leave the device.
