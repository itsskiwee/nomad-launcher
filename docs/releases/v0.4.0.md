# Nomad Launcher 0.4.0 — Handheld ready

Nomad now works from a controller, sets up your emulators on its own, finds cover art,
keeps saves in sync between devices and stays fast with thousands of games.

- **Controller navigation.** D-pad, stick and buttons drive every screen: A plays, B goes
  back, X/Start opens a game's menu, Y favorites, L1/R1 switch pages, Select opens Settings.
- **Emulators set themselves up.** 21 systems, now including GameCube, Wii, 3DS, Vita,
  Switch, Saturn and Windows (Winlator). Nomad uses the first installed emulator; choose
  another per system (Settings → Library) or per game (⋯ → Play with).
- **Cover art on its own.** Box art downloads from libretro-thumbnails; a cover you pick wins.
- **Tidy library.** Multi-disc sets, cue sheets and regional versions show as one game with
  a version chooser; BIOS and data folders stay out; hide anything else.
- **Bring your ES-DE library.** Import covers, preview videos, titles and favorites.
- **Video previews** play behind Home while a game is selected.
- **Save sync.** Two-way, newest-wins sync of emulator saves through any folder that syncs
  between devices (Syncthing, a cloud drive). Nothing is deleted; replaced saves are kept.
- **RetroAchievements** progress in each game's menu (connect in Settings → Playtime).
- **PS2 widescreen patches** from NetherSX2's own database, switched per game (root).
- **Second screen** support for dual-screen handhelds.
- **Faster.** With a 2,000-game library the Library opens in 13 ms instead of 558 ms and
  scrolls without dropped frames; covers use less memory.

Network use is opt-out for cover art (thumbnails.libretro.com) and opt-in for
RetroAchievements; see the privacy notes in the repository.

## Install

Download **nomad-launcher.apk** below and install it over your existing Nomad.
The package and signing identity are unchanged, so your library and settings remain.
Requires Android 8.0 or later. SHA256SUMS and signing certificate details are attached.
