# Nomad Launcher 0.4.0 — Open Roads

Open Roads expands Nomad from its original launcher into a home for more of your
game collection: controller navigation, automatic covers, and more systems with
emulator choices built in. The name reflects easier access to your library across
systems and devices. Version 0.4.0 marks a substantial feature release rather than
a patch; Nomad remains an early release with compatibility work ahead.

## What changed

- **Controller navigation:** D-pad, hats, left stick, face and shoulder buttons.
  A launches, B returns, X/Start opens options, Y favorites, and Select opens Settings.
- **Automatic artwork:** libretro box art with cached title/region matching and
  retries after offline fetches. No artwork service account is required.
- **More systems and emulator choices:** 21 systems, including GameCube, Wii, 3DS,
  Vita, Switch, Saturn and Windows through Winlator. Choose an installed emulator
  automatically, per system, or per game; emulator cores and BIOS remain separate.
- **Library organization:** regional-version selection, disc/playlist grouping,
  hidden games, junk-folder filtering and scans of up to 3,000 games.
- **Media import and previews:** matching ES-DE/Skraper covers, local MP4 previews,
  titles, favorites and hidden flags.
- **Save sync:** mirror selected emulator save folders to a shared folder that can
  be moved between devices by tools such as Syncthing. Root can discover supported
  emulator save locations. Backup failures now stop local replacement; content
  comparisons detect changes when file timestamps are unavailable.
- **RetroAchievements:** optional username/Web API key connection and progress for
  supported cartridge, arcade and PSP ISO games.
- **PS2 widescreen patches:** use NetherSX2's bundled community database for
  identified PS2 ISOs, with per-game choices and root access.
- **Second-screen presentation:** selected artwork and game information on an
  Android presentation display, including Library/Favorites controller selection.
- **Large-library performance:** smaller routine state updates, less repeated
  parsing/rendering, and preserved controller focus during Settings refreshes.

## Known issues and scope

- Different non-Latin titles can be incorrectly grouped as versions of one game.
- Playlists referencing subfolders can leave duplicate library entries.
- Gamelist `<image>`/`<video>` paths are not resolved; import depends on supported
  folder layouts and matching media filenames. Daijisho-specific import is absent.
- GameHub, ScreenScraper and SteamGridDB integrations are not included.
- RetroAchievements hashing does not cover PS1, PS2, NDS or GameCube. PS2 widescreen
  identification requires plain ISO files, not CHD/CSO/GZ.
- Physical-controller flows, newly added emulator handoffs, authenticated live
  RetroAchievements, real video playback and physical dual-screen hardware still
  need verification for this release. Save sync has not been validated across
  two physical devices in this review.

## Install and compatibility

Requires Android 8.0 or later. The package ID remains `com.rawal.pocketdeck` and
this APK uses the existing release signing key for update compatibility. Root
remains optional and is required only for features that explicitly use it.
The APK, SHA256SUMS and signing certificate metadata are attached to this release.

## Validation

- Startup and idle-cleanup checks passed; nine browser tests passed, with the
  optional documentation screenshot test skipped.
- Java suites passed for artwork, cover matching, save sync, RetroAchievements
  hashing, PS2 patches, playtime and battery calculations.
- Independent regressions confirmed local-save preservation on backup failure,
  timestamp-free save updates, Settings focus retention, second-screen selection,
  and insertion of missing PS2 widescreen preferences.
- Debug and signed release APK build validation; GitHub Actions checks source and
  the development APK. Clean-install and signed-upgrade smoke tests on physical
  hardware remain outstanding, so this release is prepared as a draft.
