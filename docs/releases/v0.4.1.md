# Nomad Launcher 0.4.1

A bug-fix release for three of the known issues listed with 0.4.0 Open Roads.

## Fixed

- **Non-Latin titles:** different games whose titles use Japanese, Chinese, Korean,
  Cyrillic or other non-Latin scripts were grouped as versions of one game. Grouping
  now compares letters and digits in any script. Existing 0.4.0 libraries are corrected
  on update without a rescan. Accented and plain Latin spellings now group together, so a
  saved version choice for an accented title may need to be picked again.
- **Playlists with subfolders:** discs that an `.m3u` lists in a subfolder, such as
  `discs/Game (Disc 1).chd` or `.hidden\Game (Disc 1).cue`, are now hidden behind the
  playlist instead of appearing as extra library entries.
- **Gamelist media paths:** media import now follows `<thumbnail>`, `<image>` and
  `<video>` paths in `gamelist.xml`, relative to the gamelist or as absolute paths inside
  the picked folder. Covers and clips found through the folder layout still take priority.

## Known issues and scope

- Playlist entries that point outside their own folder (`../`) or to another storage
  location still leave those discs in the library.
- Gamelist media paths under `~/` or outside the picked folder are not resolved.
- The other 0.4.0 scope notes still apply: no Daijisho-specific import; no GameHub,
  ScreenScraper or SteamGridDB integrations; RetroAchievements hashing does not cover
  PS1, PS2, NDS or GameCube; PS2 widescreen identification requires plain ISO files.

## Install and compatibility

Requires Android 8.0 or later. Same package ID (`com.rawal.pocketdeck`) and release
signing key as 0.4.0, so it installs as an update. The APK, SHA256SUMS and signing
certificate metadata are attached to this release.

## Validation

- New `LibraryTest` Java suite covers grouping keys (ASCII keys unchanged from 0.4.0,
  Japanese/Cyrillic separation, kana voicing marks kept, Latin accents and full-width
  forms folded), playlist path normalisation and storage-path mapping. All six Java
  suites and the browser tests pass.
- On the primary device (Redmi Note 8, Android 13), installed over 0.4.0: two Japanese
  titles appeared as separate games; a playlist listing both discs in `discs/` produced
  one entry; a gamelist whose cover sat in an unrecognised folder under a non-matching
  name, and whose clip used an absolute `/storage/emulated/0/...` path, imported both.
