Nomad's first packaged public release: a landscape Android game launcher with cover
browsing, swipeable Favorites, custom artwork, video backgrounds, and music controls.

## Install

Download **nomad-launcher.apk** below and open it on Android 8.0 or newer. No account
or API key is required. Games and emulators are supplied separately.

For an existing official install, install this APK over it to preserve settings
and game-folder access. Do not uninstall first. Debug builds install separately as Nomad Dev.

## In this release

- Home → Favorites by swiping up; swipe down to return.
- Explicit game options menus and corrected Favorites spacing.
- New Nomad icon with themed-icon support.
- Startup fallback and recovery for an unresponsive/lost WebView renderer.
- Root features are optional and off by default for new users.
- First launch preserves your system wallpaper and screen timeout.
- Music access uses Android's notification-access settings.
- MIT license, build instructions, contributor guides, and automated checks.

## Compatibility and validation

Primary physical-device testing: Redmi Note 8 Pro (`begonia`), Android 13.
Clean-install and upgrade checks passed on the test phone. Browser tests cover
empty startup, Favorites sizing, game menus, performance UI states, and blocked
video color sampling; Android debug and release builds pass. Broader Android/WebView and
emulator compatibility remains a community testing priority.

Root performance profiles support validated `begonia` hardware only. Other rooted
features are opt-in. Existing dedicated-device installs retain their root setting
on upgrade. See the compatibility guide before enabling advanced controls.

The APK contains no ROMs, BIOS files, emulator binaries, commercial covers, or video
themes. Documentation screenshots use original demo assets.
